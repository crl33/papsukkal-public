# Schema — the rules of this map

Closed set. A card that is neither of these types does not belong here.

## Node types

| `type:` | Lives at | Carries |
|---|---|---|
| object | `objects/<cluster>/<slug>.md` | a noun: what it is, why this shape, what it hits |
| process | `processes/<slug>.md` | a verb: input → movement → output, with steps |

## Clusters

| Cluster | Holds | Applies to |
|---|---|---|
| `wind` | the breeze model — field and per-plant response | V1 and V2 (V2 holds a copy) |
| `v1-scene` | V1's synthesised meadow: geometry, materials, optics | V1 only |
| `v2-layers` | V2's photo decomposition and deformation | V2 only |
| `pipeline` | offline asset build, dev gates, measurement tooling | both |
| `repo` | contracts that span both versions | repo-wide |

## Frontmatter

`type`, `cluster`, `universe` (live / leftover / ghost), `status`
(stub / verified / stale), `entity` (the owning source path).

`status: verified` requires a date, a commit, and `path:line` citations in the
body. A confident wrong date is worse than `stub`.

## Naming

- Slugs: kebab-case, named for the noun as an editor would ask for it
  (`locked-camera.md` — named for the concept, not after the source file
  `cameraConfig.ts` it happens to live in).
- `_meta/` and `_templates/` sort to the top and are about the map, not of it.
- `_index.md` is hand-maintained *stub lines only*; card bodies are never
  copied into it.

## Entry files

This map has no entry file of its own — `CONTEXT.md` is its contract and
`../CONTEXT.md` routes into it. The repo's entry files (`CLAUDE.md` and
`agent-workspace/CLAUDE.md`) each have a generated byte-identical `AGENTS.md`
twin, produced by `node scripts/sync-twins.mjs`. Never hand-edit a twin.

# 30-experiments — what was tried, and what it actually cost

One job: stop the next agent repeating a failure that has already been paid for.

## Inputs

- Reference (every run): `../20-visual-gates/gates.md` — how outcomes are measured
- Working (this run): your change, and the before/after gate numbers

## Process

1. **Before starting**, grep this folder for what you are about to try. Several
   entries here are failures that look like obvious good ideas.
2. Do the work. Capture gate numbers before and after.
3. Write one file: `YYYY-MM-DD-short-slug.md`, using `_template.md`.
4. Record the numbers even when the result was good. Especially then.

## Outputs

- One file per experiment. Never edit someone else's entry — append a new one
  if you learn it was wrong.

## Human check

Does the entry say what the numbers were and what you would do differently?
An entry that only records intent is not worth its bytes.

## Naming

`YYYY-MM-DD-slug.md`. Chronological order is the useful order here — the same
surface gets revisited, and the sequence is the story.
